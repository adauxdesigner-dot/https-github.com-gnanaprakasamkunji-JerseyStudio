# Known Limitations and Risks

Start this document before coding and update it continuously.

- Offline devices cannot learn about remote revocation until they reconnect.
- A person with full control of their own computer may bypass local protections or inspect local files.
- Local clock manipulation can complicate offline expiry enforcement.
- Print-ready output depends on validated dimensions, color profile, bleed, font handling, and machine-specific requirements.
- Windows and macOS packaging, signing, secure storage, and update behavior require separate tests.
- No cloud data transfer claim is accepted until network traffic has been inspected.
- No security/compliance certification may be claimed without independent evidence.
